DreamWeaver

O que é?

O Macromedia DreamWeaver é um software de criação para a web criada pela Macromedia (agora Adobe Systems), que está aualmena na versão CS3. Versões iniciais da aplicação serviam como um simples editor HTML WYSIWYG ("What You See is..")
