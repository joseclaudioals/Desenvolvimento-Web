1. criar uma atividade em Python simulando o Jogo da Mega-Sena usando a biblioteca 'random'. O jogo consiste em gerar 6 números aleatórios e o usuário deverá tentar adivinhar quais são esses números.

 ### Passo a Passo:
 1. Gerar os Números Sorteados: Vamos gerar 6 números aleatórios entre 1 e 60 (como na Mega-Sena).
 2. Receber os Números do Usuário: O usuário escolherá 6 números para tentar adivinhar os sorteados.
 3. Comparar os Números: Vamos comparar os números escolhidos pelo usuário com os números sorteados.
 4. Exibir o Resultado: O programa dirá quantos acertos o usuário teve.
